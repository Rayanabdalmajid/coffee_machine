# Coffee Machine

A command-line coffee machine simulator made with Python. It takes your order, checks the machine's resources, processes coin payment, and gives back your change.

# Features
- Choose from 3 drinks: DRINK 1, DRINK 2, DRINK 3
- Type `report` to see the remaining resources (water, milk, coffee, money)
- Type `off` to turn the machine off
- Pay with pennies, nickels, dimes, and quarters
- Gives back change if you pay more than the price
- Says "Sorry, not enough money" if the payment is too low
- Subtracts the used ingredients from the machine after each order

# How to run
1. Install Python 3
2. Download or clone this repository
3. Run:
   python main.py
